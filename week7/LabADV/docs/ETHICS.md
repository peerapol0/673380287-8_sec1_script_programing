# แนวทางจริยธรรมและกฎหมายในการ Web Scraping

1. ตรวจสอบและเคารพ `robots.txt` ของเว็บไซต์ก่อนเริ่ม scrape
2. อ่าน Terms of Service และหลีกเลี่ยงเว็บไซต์ที่ห้าม scraping
3. ใช้ rate limiting และหน่วงเวลาอย่างสุภาพ ไม่ส่งคำขอจำนวนมากพร้อมกัน
4. ใช้ User-Agent ที่ระบุตัวตนของ scraper อย่างโปร่งใส
5. ห้ามหลบเลี่ยงระบบป้องกันหรือใช้ข้อมูลเพื่อเจตนาร้าย
6. เคารพลิขสิทธิ์และความเป็นส่วนตัวของข้อมูลที่เก็บ
7. เมื่อไม่แน่ใจ ควรขออนุญาตจากเจ้าของเว็บไซต์ก่อน
