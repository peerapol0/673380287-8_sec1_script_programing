# LabBasic: Introduction to Web Scraping

โปรเจกต์นี้สาธิตการใช้ `requests` ดาวน์โหลด HTML และใช้ `BeautifulSoup4` ดึงชื่อหนังสือและชื่อบทจาก Automate the Boring Stuff with Python

## Setup และการรัน

จาก root ของ workspace:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r week7\LabBasic\requirements.txt
cd week7\LabBasic
python main.py
```

ผลลัพธ์จะแสดงชื่อหนังสือและรายการชื่อบทใน Terminal
